# iPad 随航工具集

把 iPad 变成 Mac 的主显示器，并且**自动连接、失败不弹窗**。

适合固定工位的场景：iPad 架在支架上当主屏，Mac mini 藏在桌下，每天开机自动连上。

## 需要什么

- macOS 13 或更新版本（Apple Silicon / Intel 都支持）
- 一台 iPad，已和 Mac 用同一 Apple ID 登录
- iPad 和 Mac 距离在蓝牙范围内

## 安装

**第一步**：双击 zip 解压，得到 `iPad随航工具集` 文件夹。

**第二步**：进入文件夹，**右键点击 `安装.command`**，选「打开」。

> 为什么要右键？因为这是自己编写的脚本，没有 Apple 开发者签名，macOS 第一次会拦。右键选「打开」会多出一个「打开」按钮，点它就行。以后就不用了。

**第三步**：会弹出终端窗口自动跑完，看到「安装完成」就好了。按任意键关窗口。

**装完检查**：屏幕右上角菜单栏出现 iPad 图标 → 成功。

> **如果终端报「安装包不完整，缺少 payload」**：说明你拿到的不是安装包，而是源码包（GitHub 上的 `Code → Download ZIP` 或 `Source code (zip)`）。源码包里只有代码，没有编译好的程序，装不了。请回到 Releases 页面，在 Assets 里下载 `iPad-Sidecar-Display-x.x.zip`。正常的安装包解压出来会有一个 `payload` 文件夹。

---

### 如果双击没反应

打开「终端」，输入 `bash ` （注意后面有个空格），然后把 `install.sh` 文件拖进终端窗口，回车。

### 如果提示「无法打开，因为无法验证开发者」

系统设置 → 隐私与安全性 → 往下拉到「安全性」→ 点「仍要打开」。

或者终端里跑：

```bash
xattr -dr com.apple.quarantine ~/Downloads/iPad-Sidecar-Display-2.2
```

---

## 装完是什么样

后台守护按设置的间隔检查：
- 没有在线实体屏 → 创建虚拟屏，连接 iPad 并设为主显示器。
- 有在线实体屏 → 自动连接待命，仍可在菜单栏手动连接。
- 没有实体屏且 iPad 不可连接时会继续重试，可在面板暂停。
- macOS 若仍将关机的显示器报告为在线，需要断开显示线才能进入无实体屏模式。

iPad 锁不锁屏都能连上，不用特意解锁。

## 菜单栏

菜单栏上有个 iPad 图标（Wi-Fi 和搜索之间），点它弹出控制面板：

- 手动连接 / 断开
- 暂停自动重连（比如你在用 iPad 做别的事）
- 打开日志

## 排查

**没连上？** 可先检查面板内的显示器和连接状态。下面的自检工具显示系统的屏幕和空闲状态：

```bash
~/Library/Application\ Support/ipad-watchdog/ipad-here
```

输出示例：

```
屏幕亮=是 已锁屏=否 有音频=否 空闲=13.5秒 → 人在=是
```

此 fork 不使用“人在”结果决定自动连接。

**看日志：**

```bash
tail -f ~/Library/Application\ Support/ipad-watchdog/watchdog.log
```

日志只在有事件时写（连接失败、弹窗拦截、连接成功），空跑不写。

**常见问题：**

| 现象 | 原因 | 处理 |
|---|---|---|
| 日志反复记 `-501` / `-1010` | iPad 不在附近、深度休眠、或关机 | 把 iPad 拿到 Mac 旁边 |
| 完全不连，也不写日志 | 发现实体屏、虚拟屏未就绪，或 iPad 尚未被发现 | 查看面板状态、虚拟屏开关和 iPad 连接条件 |
| 连上但主屏不对 | 显示器布局被改过 | 等下一次 10 秒检查会自动修正 |

## 卸载

双击 `卸载.command`，或者终端里跑 `./uninstall.sh`。会问一次确认，输入 `y` 回车。

随航本身是 macOS 系统功能，卸载本工具不影响你手动使用随航。

## 已知限制

- 用的是 macOS 私有框架 `SidecarCore`，未来系统大版本可能失效。失效表现：日志持续记「SidecarCore 加载失败」
- 应用是自签名的，首次运行可能被 Gatekeeper 拦，右键 → 打开即可
- 有些显示器关闭电源后仍被 macOS 报告为在线，会让自动连接保持待命。
