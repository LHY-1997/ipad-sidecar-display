# iPad 随航 2.4.1

双击「安装.command」安装2.4.1 版。它使用独立的应用名称、标识、配置和后台服务。

安装后会切换到 2.4.1 模式，暂停原版的两个后台服务并退出原版面板，避免两个版本同时操控随航。原版的应用文件和配置保留。测试模式会在重新登录后继续生效。

要切回原版，双击「恢复原版.command」。要再次切换，双击「切换到 2.4.1.command」。这两个命令也保存在 `~/Library/Application Support/ipad-watchdog-test/`。

有实体屏时 2.4.1 版不会自动连接 iPad。macOS 如仍将关闭电源的显示器报告为在线，会被视为有实体屏。没有在线实体屏时，2.4.1 版创建虚拟屏并尝试连接 iPad。

双击「卸载.command」可卸载 2.4.1 版并恢复切换前的原版服务状态。
